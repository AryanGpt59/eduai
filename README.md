# EduAI

An independent, local-first classroom video review demo. This repository was created as a standalone implementation from the supplied product brief; it is not a GitHub fork and does not copy files from the referenced repositories.

## What it does

- Samples an uploaded video locally and detects face locations with OpenCV's bundled Haar cascade.
- Assigns temporary anonymous track labels and accumulates observed video time across short detection gaps.
- Lets the teacher set an attendance confirmation threshold.
- Optionally measures one-second audio levels from a separate uploaded audio file. It does not transcribe speech.
- Shows separate video and audio timelines, exports CSV files, and offers conservative rule-based review prompts.
- Optionally stores aggregate session summaries in a local SQLite database. It does not save media or track-level attendance in history.

## What it does not do

- It does not recognize or verify a student's identity, connect tracks to a roster, or guarantee accurate attendance.
- It does not estimate emotions, attention, understanding, or learning.
- It does not use an external AI service. Teaching prompts are rule-based, not generated by an LLM.
- It does not provide real-time webcam capture, a hosted service, PDF reports, or a validated classroom deployment.

## Run locally

Requirements: Python 3.11 or later.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

On macOS or Linux, activate the virtual environment with `source .venv/bin/activate` before installing dependencies.

Upload a supported MP4, AVI, MOV, or MKV video. Audio is optional and must be uploaded separately. Sampling is limited to about two frames per second and a configurable maximum number of frames. A successful face detection is not an identity match. Each track ID is temporary and applies only to one analysis run.

## Tests

```powershell
python -m unittest discover -s tests -v
```

These tests cover anonymous tracking rules, observed-time attendance, activity prompts, and local summary storage. They do not measure face-detection accuracy, identity fairness, or classroom suitability.

## Data handling

Video and audio are processed by the local Streamlit process. The audio module calculates signal levels only; speech content is not recognized. Uploaded video is held temporarily during analysis and deleted when processing completes. If the application is forcibly stopped, the operating system may retain a temporary file. Session history is opt-in and stores aggregate counts/settings only. The application makes no cloud API calls.

Before using any classroom analytics tool with real people, obtain required consent, set a suitable retention policy, and follow applicable school policy and law. Treat outputs as uncertain measurements for teacher review, never as automatic decisions about students.
